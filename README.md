# Screen Translator

Прозрачное окно поверх всех окон: любой текст под его «дырой» распознаётся (OCR) и переводится прямо на месте.

- Перевод: Google (онлайн) или офлайн (Opus-MT). Кнопка `G` / `⚡` переключает.
- Окно: тащить за рамку, менять размер за угол `◢`.
- Хоткеи: `Ctrl/Cmd+Shift+T` — пауза, `Ctrl/Cmd+Shift+H` — скрыть/показать.
- Mac: разрешить «Запись экрана»; при «повреждено»: `xattr -cr "/Applications/Screen Translator.app"`.
- Релиз: `git tag v0.3.0 && git push origin v0.3.0` — файлы появятся в Releases.

## macOS: разрешение «Запись экрана»
Если после обновления приложение снова просит разрешение, один раз выполните в Терминале:
`tccutil reset ScreenCapture com.example.screentranslator`
затем запустите приложение и разрешите запись экрана. Дальше разрешение сохраняется и между новыми сборками.

## Windows: если не видит текст / тормозит
- Трей → «Диагностика: что видит программа» — откроется папка с кадром, поданным в OCR (`ocr-input.png`), и распознанным текстом (`ocr-result.txt`). Чёрный кадр = проблема захвата, мусор в тексте = проблема OCR.
- Трей → «Прятать перевод на время снимка» — включите, если кадр чёрный или в нём виден уже переведённый текст (на Windows ниже 10 v2004 режим включается сам).
- Выбирайте язык источника явно, а не «Авто»: OCR при «Авто» читает только English+Русский.
- Офлайн-перевод использует не больше ~1/3 ядер процессора; «Точнее (NLLB)» заметно лучше Opus-MT, но медленнее.
